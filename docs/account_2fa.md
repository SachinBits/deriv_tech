# Two-Factor Authentication (2FA)

Two-factor authentication adds a second step to sign-in, so a stolen password alone is not enough to access an account.

## How 2FA works

2FA uses TOTP authenticator apps. After entering their password, users type the six-digit code shown in their authenticator app. Codes change every 30 seconds.

## Backup codes

Each user gets 10 one-time backup codes when they turn on 2FA. Each backup code works once. Users should store the codes somewhere safe and offline, such as a password manager.

## Resetting 2FA

Resetting 2FA requires identity re-verification. Users who lose access to their authenticator app and their backup codes must complete identity re-verification before 2FA can be reset. Support agents must never reset 2FA from a chat or email request alone.

## Turning 2FA off

Users can turn 2FA off from security settings after entering a current code from their authenticator app.
